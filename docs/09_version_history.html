Version history

2026-11-18 v1.1.3 build 015

  • bug: the application kept running after it was closed (on macOS, it stayed in the Dock and had to be force quit) because map tile download threads could hang
  • bug: map tiles could not be downloaded on Linux because the SSL certificates were not found

2026-11-17 v1.1.2 build 014

  • bug: the application crashed on macOS when it was closed
  • feature: macOS (Apple silicon) and Ubuntu/Linux (x86_64) versions, in addition to Windows; installers are built automatically on GitHub
  • feature: HTML report exports all inputs, the system diagram, profiles and charts; chart data can be downloaded as CSV
  • feature: the system diagram is shown on the results page
  • feature: water tank level is an optimization variable; water cannot flow from the tank back into the water grid
  • feature: power consumption of the compressor before the H2 tank, of the H2 sales compressor (per customer) and of the O2 sales compressor is calculated instead of entered
  • feature: compressors keep only the minimum inlet and maximum outlet pressure
  • feature: battery lifetime input in BESS, separate from the power converter
  • feature: “Restore defaults” buttons in waste heat sections
  • feature: rename dialogs are preloaded with the current name
  • feature: HPM tab removed from RESu
  • feature: RESu can be used when electricity import is not possible (import from the supplier is blocked)
  • new solver parameters for faster solving
  • improved preprocessing and postprocessing times
  • bug: non-green energy appeared in the results although only green sources were available (electricity bus model updated)
  • bug: PVGIS and renewables.ninja profiles converted to local time; fixed time of plots
  • bug: components of a copied scenario pointed to the original scenario
  • bug: names of fuel cell stacks in the investment table
  • bug: waste heat error when local consumption is not used
  • bug: wind farm error when importing renewables.ninja profiles
  • bug: default price for water tank
  • bug: water tank financials
  • bug: fixed excessive memory use in heat modelling
